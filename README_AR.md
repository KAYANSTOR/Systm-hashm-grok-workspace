# إصلاح الموظفين + المزامنة العالقة + المدير + الجلسة

التاريخ: 2026-09-11 | Supabase

## ماذا يصلح هذا الأرشيف؟

1. **الموظفون لا يظهرون**
   - غالبًا لأن الحساب بلا دور admin / بلا employees.read
   - زر «تفعيل حسابي كمدير النظام» في شاشة الموظفين والإعدادات
   - يمنح دور admin + كل الصلاحيات ويربط ملف موظف إن لزم

2. **رسالة «جارٍ مزامنة / عملية معلقة» باستمرار**
   - كانت تحسب العمليات الفاشلة المستنفدة كـ«معلقة»
   - الآن تُحذف من الطابور بعد استنفاد المحاولات
   - زر تنظيف في الشريط العلوي وفي الإعدادات

3. **حسابك = المدير**
   - ensureMyAccountIsAdmin من الإعدادات أو الموظفين

4. **الجلسة**
   - rememberMe=true + صلاحية جلسة سنة
   - الحساب يبقى مفعّلًا طالما لديه دور أو ربط موظف فعّال
   - إيقاف حساب الموظف أو أرشفة الموظف يمنع الوصول (يظهر تسجيل الدخول عند الحاجة)

## طريقة الرفع
فك الضغط في جذر المستودع → git add → commit → push

## بعد النشر
1. سجّل الدخول
2. الإعدادات → «تفعيل حسابي كمدير النظام» مرة واحدة
3. إن بقيت رسالة المزامنة: «تنظيف عمليات المزامنة العالقة»
4. افتح قائمة الموظفين — يجب أن تظهر الصفوف
